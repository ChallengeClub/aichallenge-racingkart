# 弱点克服機構の試作と評価

## 1. これまでのアプローチの総括

End-to-End制御は、TinyLiDARNetの操舵を主制御とし、車輪速比例制御、4 m以内のLiDAR安全残差、直線限定2.75 m/sブーストを段階的に追加してきた。

- 2.5 m/s基準ではNPCなし連続周回、NPCあり500秒無停止を確認した。
- 一律2.75〜3.25 m/sはNPCなしでは速いが、NPCありでは停止した。
- 正面12 m以上かつ小操舵の場合だけ2.75 m/sにする方式は、安定性を維持して約3%短縮した。
- 残る弱点は、単一スキャンの距離閾値だけで判断し、接近の時間変化、速度超過、接触後のスタックを扱えない点だった。

## 2. 試作した弱点克服層

### 2.1 TTC予測減速

連続する前方LiDARクリアランスから接近速度を推定し、TTC（衝突までの余裕時間）が3秒未満のときだけ速度目標を縮小する。単発のLiDAR飛び値を避けるため、3サンプルの中央値と5スキャンの保持を使う。操舵には介入せず、既存の近距離安全残差を最後の防護として残す。

### 2.2 スタック回復

一度0.8 m/s以上で走行した車両が2秒以上0.2 m/s以下になった場合だけ、前方距離にかかわらず左右LiDARの空いている側へ安全残差を強制する。発進中の低速は対象外とした。

### 2.3 速度超過連動ブレーキ

通常は従来どおり最小加速度を-0.2とし、目標を0.3 m/s以上超えた場合だけ-0.6まで制動を許す。下り坂でも常に強く減速するのではなく、実測速度超過へ限定して介入する。

3機構は設定で個別に有効化できる。評価の結果、現時点ではすべて既定無効とし、確認済みベースラインの挙動を保っている。

## 3. 評価結果

| 条件 | 結果 | 分かったこと |
|---|---|---|
| 2.5/直線2.75 m/s + TTC、NPCなし | 450秒無停止、194.7秒/190.7秒 | 安定動作したが、採用ベースラインの190.3秒/186.8秒より約2%遅い |
| 一律3.0 m/s + TTC、NPCあり | 1周165.9秒、287秒で停止 | TTC介入率は最終約13%、高速条件の安定化には不足 |
| 上記 + スタック回復 | 1周181.6秒、310秒で停止 | 停止を検知し258スキャン介入したが、前進操舵だけでは復帰不能 |
| 上記 + 速度超過連動ブレーキ | 1周167.8秒、303秒で停止 | 最大速度を4.21から2.81 m/sへ抑えたが、横方向の失敗は残った |
| 2.5/直線2.75 m/s + 連動ブレーキ、NPCあり | 1周182.5秒、312秒で停止 | ランダムNPC条件で既存の500秒安定性を再現できず、採用不可 |

NPCありの`/awsim/status`は複数車両の値が混ざるため、周回値は参考である。停止判定は自車輪速が15秒以上0.2 m/s未満になったことを使った。

単体テストは23件合格し、ROS 2ワークスペース25パッケージのビルドも成功した。各試験のJSONは次に保存した。

- `output/ttc-prototype-no-npc.json`
- `output/ttc-prototype-3mps-e2e.json`
- `output/ttc-prototype-3mps-recovery-e2e.json`
- `output/ttc-prototype-3mps-adaptive-brake-e2e.json`
- `output/adaptive-brake-final-e2e.json`

## 4. 結論

時間変化を見る仕組みは実装でき、TTCは通常走行の約13〜16%だけ介入した。速度超過連動ブレーキも、3.0 m/s試験の最大速度を約1.4 m/s抑える明確な局所効果を示した。しかし、どの構成もNPCあり500秒を満たさず、既定採用できる総合効果は確認できなかった。

停止位置が繰り返しセクション5付近で、接触後にはTTCが無限大（接近なし）になることから、主因は縦速度だけでなく、TinyLiDARNetの横方向復帰能力と考えられる。前進しながら左右へ切るだけの回復では、車体が壁やNPCへ横向きに接した状態を解消できない。

## 5. 次の取り組み

次は閾値をさらに調整するより、失敗状態そのものを教師データへ戻す仕組みを優先する。

1. セクション、LiDAR、操舵、速度、安全層の介入状態を同時記録する。
2. 停止前10〜15秒を自動抽出し、教師制御または人間の修正操作を付ける。
3. DAggerでコース端、壁向き、NPC接近時の画像/LiDARを追加学習する。
4. 同じ固定シードまたは複数回試験で、完走率とタイムの信頼区間を比較する。
5. 横方向の復帰率が改善した後、今回のTTCと連動ブレーキを再度有効化する。

今回の試作は採用設定ではなく、次の学習・評価ループで再利用する安全層の候補として残す。
